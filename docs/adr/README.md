# 架构决策记录（ADR）

本目录存放 LitePortal 的架构决策记录。

## 规则

- **只追加，不修改**。已 `accepted` 的记录不可篡改——决策记录的价值就在于可回溯「当时为什么这样定」。
- 需要变更某个已接受决策时：**新增一条 ADR** 说明变更，旧记录原样保留，并在新记录里标注 `取代：ADR-xxxx`。
- 文件名格式：`NNNN-短横线小标题.md`，序号只增不复用。
- 每条记录至少包含：背景、决策、理由、后果（正面 / 负面）。
