# LitePortal 构建与部署

> 后端为 Go（单文件二进制，CGO_ENABLED=0），前端为 Vue 3（Node/pnpm 构建）。本文说明本地构建、产物结构与部署方式。

## 一、本地构建

根目录 `build.sh`（bash 脚本，仅负责编排，不含后端运行时）一次性产出 `dist/`：

1. 清理 `dist/` 与前端构建缓存；
2. 前端：`cd frontend && pnpm install && pnpm run build:prod`；
3. 复制 `frontend/dist/*` → `dist/web/*`；
4. 后端：`cd backend && go build -o dist/server .`（CGO_ENABLED=0 纯静态二进制）；
5. 复制 `backend/migrations/schema.sql` → `dist/migrations/schema.sql`；
6. 复制 `backend/.env.production` → `dist/.env`。

```bash
bash build.sh
```

> 也可分步构建：后端单独 `cd backend && go build -o server .`；前端单独 `cd frontend && pnpm run build:prod`。

### 产物结构

```text
dist/
├── server            # 后端单文件可执行（Go 编译；Windows 为 server.exe）
├── web/              # 前端构建产物（被 server 在 production 托管）
├── migrations/
│   └── schema.sql    # 建表 DDL
├── .env              # 由 .env.production 复制而来（非敏感默认值）
└── data/             # 运行时 SQLite 目录（首次启动自动创建）
```

## 二、运行

```bash
cd dist && ./server      # 默认端口 8080（见 .env 的 PORT）
```

- Windows：`.\server.exe`
- Linux / macOS：`./server`（确保有执行权限）
- 浏览器访问 `http://<host>:8080`。

配置覆盖：改 `dist/.env`（或运行时 `export PORT=xxxx`）；本机开发直接 `cd backend && go run .`（读 `backend/.env.development`）。

## 三、多平台打包

`.github/workflows/pkg.yml` 用 Go 交叉编译（**不再依赖 `@yao-pkg/pkg`**）产出三平台二进制：

- `GOOS=linux/darwin/windows` × `GOARCH=amd64`
- 产物为 `dist/server`（及 Windows 的 `server.exe`），与本地 `bash build.sh` 结构一致。

## 四、Docker 部署

`.github/workflows/docker.yml` 基于仓库根 `Dockerfile`（`golang:1.22` 构建 → `alpine:3.20` 运行），构建的是**当前 Go 版**镜像，`context: .`，无 Node 依赖。

- 打 `v*` tag 时推送到 Docker Hub 与 GHCR。
- 也可在 Actions 页手动触发（`workflow_dispatch`）：**只构建、不登录、不推送**，用于在不发版的前提下验证 `Dockerfile` 仍可构建。

```bash
docker build -t liteportal .
docker run -d -p 8080:8080 -v $(pwd)/data:/app/data liteportal
```

## 五、数据存储

- 首次运行按 `migrations/schema.sql` 自动建表；SQLite 文件位于 `./data/liteportal.sqlite`（相对进程工作目录）。
- `data/` 已被 `.gitignore` 忽略，不入库。

## 六、常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 端口 8080 被占用 | 其他进程占用 | 改 `PORT`（`.env` 或环境变量） |
| 改了 `.env` 不生效 | 工作目录不对，或键被更高优先级覆盖 | 见 `docs/configuration.md` §2：`process env` > `.env`（本地） > `.env.<NODE_ENV>` |
| 前端深链刷新 404 | production 未走 SPA fallback | 须经本服务访问（已内置 fallback），勿直接打开 `web/index.html` |
